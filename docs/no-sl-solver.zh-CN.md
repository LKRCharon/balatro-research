# noSL 战斗求解与成长目标

## 当前实现

`headless/no_sl_solver.py` 是本轮冻结战斗策略；`no_sl_solver_v2.py` 是独立、显式选择的新版本。两者只接受公开观察，不读取种子、未来商店或隐藏抽牌顺序，也不执行存档恢复。v2 尚未接受新一轮完整游戏评估。

v1 枚举可见出牌候选，进行有预算的公开剩余牌分布抽样与两步前瞻；不支持的动态机制进入标记明确的启发式。v2 在弃暗牌前检验可见出牌的模型保守分，错印贡献置零；并保护当前计分核心增强牌及留手钢铁、黄金。模型界不等于原引擎保证。

调用示例（在 headless 模块路径下）：

```python
from no_sl_solver_v2 import choose
decision = choose(public_observation, {"samples": 8, "max_candidates": 10,
                                       "time_budget": 3})
```

参数名应以 `no_sl_solver.config_values` 为准；返回动作须经合法性检查后只执行一次。超时或响应不明确时先核对动作是否已执行，不能盲目重发。未来接入新评估必须冻结入口、依赖和配置，不能替换已经完成的 v1 轨迹。

## 最优性的边界

固定可见手牌的立即得分，可以在规则模型完整且枚举完整时寻找最大值。当前实现仍有机制覆盖与排序枚举边界。整个盲注的最优动作还依赖未知抽牌、随机触发及成长代价，属于部分可观察决策问题，不能用立即最高分替代。

令公开历史形成信念分布 b，剩余目标为 T，手数为 h，弃牌为 d：

`V(b,T,h,d) = max_a E_b[V(b', T-score(a), h', d')]`。

立即生存的终值为 1，失败为 0；到下一商店的价值还需包含现金、永久牌改造、牌型等级、成长小丑、易腐剩余回合。精确求解需要可信转移模型与完整状态，当前采用有限候选和抽样近似。样本通过比例未校准，不能称为通关概率。

## 本轮失败导出的下一步

1. 比较真实得分与预测，先修计分时序，再扩大搜索。玻璃发生在小丑加法倍率之前；不能把之后的绿色小丑、巴士等加法倍率一起乘上玻璃倍率。
2. 以未来生存约束评估消费：当前常用手的分数分布、下一盲注需求、Boss 条件冲突和临时牌到期必须同时报告。现金多但未转战力也会失败。
3. 资源模型计入利息损失、每回合租金、卡包未匹配选项、刷新成本、弃牌造成的绿色／横幅／拉面损失，以及蓝色小丑随抽牌递减的筹码。
4. 将可见状态边际分数用于诊断，而非因果卡牌排名；出售会改变槽位、抽象、侠盗、模具及交易触发。需要完整重算。
5. 新候选只在 TRAIN 开发；冻结后独立验证，保留失败和中断。重打旧失败种子属于事后复盘，不计独立胜率。

13 局观察不足以判定任何卡是“设计差”。后续平衡研究须分别统计出现机会、可负担性、购买率、机制触发覆盖、替代成本与组合交互。趣味性可测路线多样性、决策分歧和构筑转型，不能由得分直接推断。
