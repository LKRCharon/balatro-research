# 资源与有效火力复盘工具

`experiments/analyze_resources.py` 是只读离线工具，只接受 `train-N` 已终局目录和显式 run allowlist；不打开种子注册表，不执行游戏，不读取 TEST。不修改任何冻结版本。

```powershell
python outputs/balatro-lab/experiments/analyze_resources.py --runs-root work/experiments/manual-ten-002 --runs 32 33 34 36 37 38 40 41 --output outputs/balatro-lab/results/manual-ten-002/resource-analysis.json
```

同名 Markdown 是简表，JSON 保存每次资源动作、离店摘要和每盲注实打统计。复打与新局可在各自目录逐局调用并存成不同报告；不能覆盖原局证据。

## 具体指标

- **机会集合**：按区域及运行时卡 ID 去重记录商品首次出现、品类、报价与首次观察时现金是否覆盖报价。缺少 ID 不强行计为独立商品。现金覆盖不是合法购买判定：信用卡、槽位、当前阶段及贴纸约束还需动作层检查。礼包选项属于揭包后信息，不作为开包前可知内容。
- **金币曲线**：每次购买、刷新、出售、使用或卡包选择记录前后现金和净变化；所有成功动作另按 method 汇总现金净变化。明确拒绝未执行的动作不计支出。
- **直接成本与利息机会成本**：报价支出与净现金变化分开，避免把购买触发返现误认为优惠。立即利息容量为 `min(cap, floor(max(0,cash)/5))`，普通 cap=5，种子资金=10，摇钱树=20。这里只报告动作前后的容量差；真实未来利息还取决于之后出入账与特殊禁息效果，不能将每步差额相加称累计损失。
- **优惠券、刷新和卡包**：分别统计报价投入；同时保留目标 key 和序列号以连接已曝光商品。现阶段不把“刷到某牌”解释为刷新增加胜率，也不把未选择项目当作已经执行的反事实。
- **小丑、消耗牌**：动作类别和 key 可关联组合规则；离店摘要保留易腐剩余数、租赁、永恒、消耗牌数量。槽位/租金/失效的机会成本需要阵容反事实，当前报告不杜撰单牌边际战力。
- **有效火力**：每盲注记录实际手分、中位手分、最终分/目标、首次出牌时所需平均手分、最终缺口；相邻盲注比较中位手分增长与目标增长。它们受抽牌、Boss、策略、留手与牌型选择共同影响，不能当成静态阵容强度或未来保底分。
- **离店短板**：保存最后离店现金与组件寿命。历史轨迹未统一保存可核验的完整前瞻估分，因此 `forward_power_estimate=null`，不得用终局结果填充。复打应由战斗求解器在离店时另存目标、可见信息估计、假设与版本。

## 原八负局初步复盘

[八局完整表](../results/manual-ten-002/resource-analysis.md) 已由原始结束轨迹生成并保存输入 SHA256。32/33 的最终缺口分别 2209/5004；34/36 都死于针，但最后离店现金分别 0/12，不能只靠“多花钱”统一解释。34 全局刷新报价共74，必须连同实际新增选项与购买考察，不能因失败就判刷新无效。38/40 最后离店现金为 -3/-6，说明现金余量已不足；41 卡包报价共60，末盲缺10780，需要复打比较不同发育分配，但当前不能断定卡包造成失败。

原局、复打和新局分别分组；学习过的八个失败种子是 TRAIN 训练案例，不能回充 fresh-seed 正式胜率。每局刷新报告可以形成待验证假设，任何冻结验证应使用独立种子及冻结策略。
